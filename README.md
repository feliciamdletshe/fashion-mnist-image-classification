# Fashion Image Classification Using Deep Learning

## Overview
This project investigates the use of Artificial Neural Networks (ANN) and Convolutional Neural Networks (CNN) for classifying images from the Fashion-MNIST dataset.

## Technologies Used 
- Python
- TensorfFlow
- Keras
- Jupyter Notebook
- Google Colab
- Numpy
- Matplotlib

## Dataset 
Fashion-MNIST

## Objectives 
- Develop ANN and CNN models.
- Compare model performance.
- Evaluate image classification accuracy
